# Журнал решений (ADR)

## [2026-08-26] Модульный монолит вместо микросервисов на старте
Контекст: срок 2-3 недели, разработка в одиночку через текстовые сессии с
Claude без агентов.
Решение: начинаем с модульного монолита с чёткими internal-границами,
выделяем сервисы только когда граница доказала свою пользу на практике.
Альтернативы: сразу микросервисы — отклонено, риск не успеть с MVP.

## [2026-08-26] Ollama (локальная LLM) вместо платного LLM API
Контекст: нет бюджета на проект.
Решение: слой `aigateway` работает поверх локальной модели через Ollama.
Альтернативы: Anthropic/OpenAI API — отклонено из-за отсутствия бюджета,
можно рассмотреть как апгрейд после защиты.

## [2026-08-26] Выносим в отдельный сервис только aigateway
Контекст: нужно продемонстрировать микросервисный подход, но времени мало.
Решение: единственное осознанное выделение в срок — aigateway, из-за
другого профиля нагрузки (инференс модели).
Альтернативы: дробить всё сразу — отклонено как избыточное дробление
без времени на его обоснование.

## [2026-08-26] Дисклеймер во всех ИИ-ответах о трендах/прогнозах
Контекст: сервис не должен выглядеть как источник финансовых советов.
Решение: любой ответ aigateway, касающийся прогнозов/трендов, обязан
явно указывать, что это не финансовая рекомендация, и опираться на
реальные данные из БД (RAG), а не додумывать цифры.

## [2026-08-26] Workflow: 3 аккаунта Claude по ролям + git как источник истины
Контекст: три бесплатных аккаунта, без агентов, текстовый формат.
Решение: роли — Архитектор / Разработчик / QA-DevOps-Доки, каждый со
своим Project (custom instructions + knowledge base = файлы docs/).
Синхронизация — вручную, через git-коммиты после каждой сессии.
Подробности — см. AI_WORKFLOW.md в корне репозитория.
